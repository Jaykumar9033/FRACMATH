# Software archive and citation

The SoftwareX manuscript identifies its source and data by an immutable GitHub commit. Use that identifier to reproduce the paper.

## Release checklist

- Select a version tag that identifies the source and datasets used in the manuscript.
- Check the license, citation metadata, reproduction commands, and data hashes.
- Create a versioned archive and record the DOI assigned to that archive.
- Use a DOI only for the code version it identifies.

The repository citation metadata is in `CITATION.cff` and `.zenodo.json`.
