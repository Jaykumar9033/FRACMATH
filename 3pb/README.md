# Three-point bending code and inputs

`matlab/` contains the MATLAB solver and benchmark inputs. `abaqus/` contains the Abaqus model builder, UMAT and extraction helpers. The root `softwarex/` folder contains current manuscript study runners and reference results.

For the current MATLAB example, open `softwarex/start_here.m` from the repository root. For matched MATLAB-Abaqus studies, follow [COMPARISON_EXTENSION.md](../softwarex/COMPARISON_EXTENSION.md). Use [plot_current_figures.py](../softwarex/plot_current_figures.py) to reconstruct current figures from saved data.

Result CSV files under this folder preserve an earlier baseline. Current manuscript medium/fine responses are in `softwarex/reproducibility/fixed_increment_extension/`; the coarse 4,000-increment pair is in `softwarex/reproducibility/fixed_increment_retry/`. The baseline is not a replacement for these matched comparisons. ODBs are generated by fresh Abaqus runs and are not required to plot the supplied CSV results.
